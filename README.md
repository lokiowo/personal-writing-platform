# 供个人使用的协作平台

一款轻量的个人写作与进度管理网页应用。无需安装依赖或启动服务器，使用浏览器即可开始写作。

## 功能

- **写作编辑器**：创建、搜索、重命名和删除文章，支持粗体、斜体、下划线及字体设置。
- **章节管理**：将长篇作品拆分为章节，并按章节编辑。
- **自动保存**：编辑内容会自动保存到当前浏览器的本地存储。
- **写作统计**：记录每日、本月和累计写作字数，查看最近 7 天趋势，并设置每日写作目标。
- **每日签到**：记录连续签到、累计积分，并兑换奖励。
- **导入与导出**：导出单篇 TXT，或备份、恢复全部作品数据。
- **响应式布局**：支持桌面和移动设备浏览。

## 开始使用

1. 下载或克隆本仓库。
2. 在浏览器中打开 `index.html`。
3. 进入“码字”页面新建文章即可开始。

本项目为纯静态网页，不需要 Node.js、数据库或其他依赖。

## 数据与备份

文章、写作记录、签到、积分和设置保存在浏览器的 `localStorage` 中，不会自动上传到服务器，也不会在不同设备或浏览器之间同步。清理浏览器站点数据可能会删除这些内容，建议定期在“统计”页面使用“导出全部备份”保存 JSON 文件；需要恢复时使用“导入备份”。

## 项目文件

- `index.html`：页面结构
- `style.css`：页面样式与响应式布局
- `script.js`：编辑器、统计、签到及本地数据逻辑
